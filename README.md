# Nei1eveN.github.io

Personal GitHub Pages portfolio for Neil Patrick Potot.

## Local Preview

This is a static site with no build step.

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## GitHub Pages Deployment

Use this repository as `Nei1eveN.github.io`. GitHub Pages will serve `index.html` from the default branch.
