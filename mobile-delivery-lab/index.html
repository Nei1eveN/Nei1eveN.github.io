Broken Flutter release

A new build reaches the test group. Its Orders screen comes back empty. Follow the failed request, choose a rollout, and check that both app versions work.

Incident summary
Flutter app 2.8

Test build · Orders screen failing

Orders API 1.12

Running backend · Supports /v1/orders

Diagnosis

What changed in 2.8?

The test build calls /v2/orders, which returns 404. App 2.7 uses /v1/orders, which the running API still supports.

Request trace
GET/v2/orders

X-App-Version: 2.8

404 Not Found
{
  "error": "route_not_found",
  "path": "/v2/orders"
}
Rollout

How should the release proceed?

Pause the rollout at the test group while you decide. Existing users will stay on Flutter app 2.7 during the gradual rollout of 2.8.
