Try gifting and checkout recovery

  1. Give a pass. Choose Gift on a workshop and enter one sample name per gift in Cart. Add another pass to see that the first name stays in place. The cart accepts up to five gifts across all workshops and requires a name for each gift before checkout.
  2. Interrupt checkout. Select Continue to checkout, then tick Simulate an interruption after payment and approve the demo payment. The shop saves the approval and the order reference in this browser before reloading.
  3. Check the recovered order. The confirmation uses the same reference and shows the gift recipients. Open Orders to find the single matching order. After you dismiss the confirmation, reloading keeps it closed and the order stays in history.

To try a failed payment, choose Decline at checkout. The cart keeps the passes and recipient names so you can try again.
